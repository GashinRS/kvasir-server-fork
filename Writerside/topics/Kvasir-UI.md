# Kvasir UI

You can interface with your pod using the Kvasir UI. For advanced operations we always refer to the actual [Kvasir APIs](API-Reference.md).

## S3
Interface with your pod as an S3 storage space. Uploaded files in the proper RDF formats, can be auto-ingested to the Knowledge Graph.
![Kvasir UI - S3](ui_s3.png)

## GraphiQL
Query all knowledge in your pod using the generated GraphQL Schema.
![Kvasir UI - GraphiQL](ui_graphiql.png)


## Changes
Create and manage Change Requests right from the UI.
![Kvasir UI - Changes](ui_changes.png)

## Slices
Create and manage Slices right from the UI.
![Kvasir UI - Slices](ui_slices.png)

Query within a Slice, using the custom created GraphQL Schema based on your Slice definition.
![Kvasir UI - Slices - Query](ui_slices_query.png)
