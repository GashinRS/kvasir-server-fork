# API Reference

> **Note on JSON-LD request & response bodies:** <br/>
> The API documentation shows the JSON-LD schema types using fully qualified URIs for the included properties.
> However, clients may compact the URIs using the `@context` property in the request bodies and expect the same for the
> returned response bodies.
> Hence, you should treat the results of the JSON-LD endpoints as potentially compacted JSON-LD, and not as plain JSON.
> {style="note"}
